司忆Demo

Windows 个人 Agent 工作台，把任务规划、工具执行、记忆与结果验证集中在桌面。

技术栈 · React · TypeScript · Tauri 2 · FastAPI · SQLite

以主页的界面示意展示核心流程，非实际操作录屏。点击播放即可观看。

  1. 01

    规划任务

    描述任务，把目标拆解为可执行的步骤。

  2. 02

    工具执行

    通过个人 Agent 的工具能力推进任务。

  3. 03

    验证结果

    查看任务执行结果，完成本轮协作。

实现重点

React 与 Tauri 构建桌面界面，Python 执行核心管理持久任务与工具；权限和审计帮助追踪执行过程。
